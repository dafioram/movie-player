Movie Player help

Everything happens on your computer. Files are read locally and never uploaded.

Opening a movie

  • Drop a movie onto the window, together with any subtitle, audio or font files. Or use Open file / Open folder.
  • A zip works like a folder, as long as the video inside is stored without compression.
  • Drop extra subtitle or audio files onto a movie that is already playing to add them as tracks.
  • Install the app (the install icon in Chrome's address bar) to open video files with “Open with → Movie Player”.
  • Space plays and pauses. Everything else is in the control bar.

My file won't play

The error message says which part failed. Two free tools fix almost everything: HandBrake (point and click) and ffmpeg (command line).

Container not supported (AVI, WMV…) but the codecs are fine: repackage without re-encoding.

ffmpeg -i "input.avi" -map 0 -c copy "output.mkv"

Video codec not supported (VC-1, DivX/Xvid, HEVC without hardware support): convert the video to H.264 and keep the other tracks.

ffmpeg -i "input.mkv" -map 0 -c copy -c:v libx264 -crf 18 -preset medium "output.mkv"

In HandBrake, choose the preset Fast 1080p30 (or a matching resolution) and add all audio and subtitle tracks on their tabs.

No sound: the details panel (the i button) shows each audio track's status. To convert one audio track to AAC:

ffmpeg -i "input.mkv" -map 0 -c copy -c:a aac -b:a 384k "output.mkv"

Compressed zip: create the zip without compression.

zip -0 -r "movie.zip" "Movie folder"

Subtitles look like gibberish: the file uses an unusual text encoding. Naming it with its language (for example Movie.ru.srt) helps the player pick the right one.

Choppy MPEG-2 playback: conversion runs in the browser. Standard-definition DVD video is easy; 1080i TV recordings may be too heavy for some computers. The details panel shows the conversion speed; below 1.0× means the computer can't keep up.

Hardware or software decoding

The details panel reports what Chrome says about decoding the exact stream. To see the decoder Chrome actually used, paste chrome://media-internals into the address bar while the movie plays. If it reports software decoding because hardware acceleration is off, turn on Settings → System → Use graphics acceleration when available and restart Chrome.

Privacy

The app stores playback positions, preferences and the location of the last movie (not the file itself) in this browser only. Use More → Clear history to remove them.
